Web-Based AI system for predicting food freshness from uploaded food images.

## 2. Overview & Problem Statement
### The Challenge
It can be difficult to judge food freshness by appearance alone. This project aims to develop a website that analyses uploaded food images to help assess food freshness.
### Target Audience
Consumers, students, and people interested in checking food freshness.
### Impact Metric
The system will be evaluated through prediction accuracy, response time, and testing results.

## 3. Architecture & Solution Logic
### Concept
Users upload a food image through the website. The system is designed to analyse the image, display a result, and save prediction records.
### Technology Stack
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js and Express.js
- Database: MySQL
- Design and collaboration: Figma and GitHub

## 4. Key Features & Prototype
- [x] Website layout for food image upload and preview
- [x] User registration and login APIs
- [x] APIs to save and retrieve prediction records
- [x] API to delete prediction records
- [ ] Frontend-backend integration
- [ ] Integration and validation of a real AI prediction model

### Phase 2 — Future Scope
